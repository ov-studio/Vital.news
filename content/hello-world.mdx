This is a test post. Copy this file to create a new one. It stays hidden until you add `publish: true` to the frontmatter.

## Creating a post

1. Create a new `.mdx` file inside `content/`, for example `content/17-10-2026/my-first-post.mdx`.
2. The folder path and file name become the URL, so that file is served at `/news/17-10-2026/my-first-post`. Folders can be nested, and the same file name can be reused in different folders.
3. Fill in the frontmatter below, set `publish: true`, and push to `main`.
4. The **Build News** workflow rebuilds `news.json` and the site picks the post up within a few minutes, no frontend rebuild needed.

## Frontmatter

| Field | Required | Notes |
|---|---|---|
| `title` | Yes | Shown on the card and in the post. |
| `date` | Yes | `YYYY-MM-DD`. Newest posts are listed first. |
| `description` | No | One-line summary for the card and link previews. |
| `author` | No | Defaults to the repository owner. |
| `tags` | No | Example: `[announcement, update]`. |
| `cover` | No | Image next to the post (`cover.png`) or a path from the repository root. PNG, JPG and GIF also work as the link-preview image. |
| `publish` | Yes, to go live | Anything other than `true` keeps the post hidden. |

## Writing

Posts are plain Markdown (tables and strikethrough work too). Raw HTML such as `<br/>` is fine. MDX imports and JSX components are not supported and are ignored. Images placed next to the post can be referenced by relative path, for example `![Screenshot](./screenshot.png)`.

## Formatting

Regular Markdown works: **bold**, *italic*, [links](/docs), lists and blockquotes.

> Blockquotes look like this.

Code blocks are highlighted:

```lua
local function greet(name)
  print("Hello, " .. name)
end

greet("Vital")
```

## Images

Put images in `frontend/public/news/` and reference them by absolute path:

```md
![Alt text](/news/my-image.png)
```
